# ملصقات الصيدلية

مُنشئ ملصقات باركود و QR للمنتجات الصيدلانية التي لا تحمل باركود، يعمل في المتصفح ويطبع على طابعات الملصقات الحرارية (مثل Xprinter) بأي مقاس.

الرابط: https://luay89.github.io/pharmacy-labels/

- Code 128 و EAN-13 و QR
- ترقيم تسلسلي تلقائي، والاسم والسعر وتاريخ الانتهاء ورقم الوجبة
- مقاسات جاهزة ومقاس مخصص
- حفظ المنتجات في المتصفح، وتصدير واستيراد Excel
- يعمل بدون إنترنت: كل المكتبات مضمّنة في `index.html`
